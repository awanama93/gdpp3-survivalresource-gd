##### Break point

Sebuah interactive prop bisa memiliki break point
Break point adalah poin yang menentukan apakah suatu interactive prop itu functional, broken, atau destroyed

### Penambahan Break Point

- Break point suatu interactive prop akan bertambah jika character [[AllyCharacterAction#Memperbaiki defense prop dan facility prop|memperbaiki]] prop tersebut
- Jika suatu prop diperbaiki, maka nilai break point akan bertambah seiring waktu
- Kalkulasi penambahan break point ketika [[AllyCharacterAction#Memperbaiki defense prop dan facility prop|perbaikan]] dilakukan dipengaruhi oleh

### Pengurangan Break Point

- Break point suatu interactive prop akan berkurang jika character [[CharacterAction#Menyerang|menyerang]] atau [[AllyCharacterAction#Menghancurkan resource prop|menghancurkan]] prop tersebut
- Kalkulasi pengurangan break point dipengaruhi oleh
