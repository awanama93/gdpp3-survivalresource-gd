Di dalam game ini terdapat sejumlah object yang memiliki behaviour beragam

### Detail informasi

Pada dokumen ini terdapat informasi tentang hal-hal berikut perihal object tersebut:

- Behaviour
  - Ini adalah informasi tentang apa saja yang mungkin dilakukan oleh object tersebut
- State
  - Ini adalah informasi tentang keadaan apa saja yang mungkin dialami oleh object tersebut
- Property
  - Ini adalah informasi tentang data yang mungkin dimiliki oleh object tersebut
