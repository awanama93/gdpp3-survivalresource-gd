Upgrade target adalah property tentang apa yang menjadi target dari suatu action [[PlayerCharacterAction#Mengupgrade equipment|upgrade equipment]] atau [[PlayerCharacterAction#Mengupgrade interactive prop|upgrade interactive prop]]

Nilai dari upgrade target adalah tipe interactive prop atau equipment. Jadi ketika suatu hal diupgrade, semua object dengan tipe tersebut akan ikut diupgrade.

Misalnya, upgrade target dari suatu upgradive interactive prop adalah apotechary table, maka semua apotechary table yang ada dalam game akan di-upgrade. Jadi bukan hanya satu apotechary table saja
