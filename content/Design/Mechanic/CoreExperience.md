### Overview

Player adalah seorang penyintas dari technological apocalypse yang membantu basecamp penyintas saat menunggu bantuan datang​

### Gameplay

##### Survival

Aspek survival dari game ini terletak pada aktivitas berikut:

- Bertahan hidup dan mengalahkan wave dari zombie robot
- Membangun radio tower untuk memanggil tim penyelamat
- Menavigasi kawasan di luar base camp yang gelap sambil menyalakan listrik di game space

##### ResourceManagement

Aspek resource management dari game ini terletak pada aktivitas berikut:

- Melakukan eksplorasi untuk mencari resource generator object
- Mengumpulkan resource dari resource generator object
- Membuat object untuk keperluan resource management atau survival dari resource
- Mengelola kesehatan para civilian
- Mengatur peran civilian dalam proses survival maupun resource management

### Referensi

##### Kingshot

Yang diambil dari game ini adalah bagian base defense ketika para perampok menyerbu desa. Pada bagian tersebut player bisa berjalan ke sana-sini dan ketika tidak berjalan, player akan menyerang musuh yang ada di radiusnya. Bagian ini digunakan sebagai referensi untuk aspek bertahan hidup dan mengalahkan wave zombie robot.

##### Dark Forest Survivor

Yang diambil dari game ini adalah bagian di mana player harus mengeksplorasi game space sambil menyalakan obor di beberapa tempat sebagai check point. Selain itu, dari game ini diambil juga bagian player harus membangun sesuatu untuk bisa menyelesaikan game. Bagian ini digunakan sebagai referensi untuk melakukan eksplorasi dan menavigasi kawasan di luar basecamp.

##### Frost World

Yang diambil dari game ini adalah bagian di mana player harus menghancurkan sesuatu untuk berprogress secara game space dan cara upgrade peralatan player. Selain itu, dari game ini diambil juga bagian objek penghasil resource ditata secara "random". Bagian ini digunakan sebagai referensi

##### Last Asylum: Plague

Yang diambil dari game ini adalah bagian mengelola tempat merawat para warga. Bagian ini digunakan sebagai referensi untuk aspek mengelola kesehatan para civilian.
