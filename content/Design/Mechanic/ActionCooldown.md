Action cooldown adalah property tentang waktu yang dibutuhkan agar suatu action dengan equipment selesai dilakukan

### Menghancurkan interactive prop

Jika character menggunakan equipment untuk menghancurkan interactive prop, seperti [[AllyCharacterAction#Menghancurkan resource prop|menghancurkan resource prop]], maka nilai action cooldown digunakan untuk hitung mundur sampai action menghancurkan resource prop dilakukan kembali selama character ada pada radius resource prop tersebut

### Menyerang object

Jika character menggunakan equipment untuk menyerang object, misalnya [[AllyCharacterAction#Menyerang enemy character|enemy character]], [[EnemyCharacterAction#Menyerang ally character|ally character]], atau bahkan [[EnemyCharacterAction#Menyerang defense prop|defense prop]], maka nilai action cooldown digunakan untuk hitung mundur sampai action menyerang dilakukan kembali selama masih ada target serangan pada radius equipment
