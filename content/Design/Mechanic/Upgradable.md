Suatu object bisa di-upgrade (upgradable) oleh [[Character#Player character|player character]]
Suatu object yang upgradable bisa diupgrade bukan dengan player character berinteraksi langsung dengan object tersebut, melainkan melalui player character berinteraksi dengan [[InteractivePropBehaviour#Upgradive|upgradive]] prop yang berhubungan dengan upgradable object tersebut
Misalnya, player ingin mengupgrade [[TipeInteractiveProp#Apotechary Table|apotechary table]], maka dia harus berinteraksi dengan [[TipeInteractiveProp#Bookcase|bookcase]] yang dikhususkan untuk apotechary table
Contoh lain, player ingin mengupgrade [[Axe]], maka dia harus berinteraksi dengan [[TipeInteractiveProp#Tool rack|tool rack]]
Suatu upgradable object memiliki [[Equipment Property#Level|level]]
Suatu upgradable object memiliki paling rendah level 0 (sudah ada object-nya di dalam game tetapi belum bisa dipakai)

### Perbedaan ally dan enemy object

Upgradable object yang dimiliki [[Character#Ally character|ally character]] bisa dimulai dari level 0
Upgradable object yang dimiliki oleh [[Character#Enemy character|enemy character]] bisa dimulai dari level lebih dari 0, bergantung dari preset yang ditentukan
